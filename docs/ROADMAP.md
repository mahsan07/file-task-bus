# Roadmap

## Phase 1: contract and local demo

- Task-card schema
- Atomic claim helper
- Folder lifecycle
- Watcher
- Digest generator
- Failure and approval lanes

## Later phases

- Reference CLI
- Cross-platform watcher
- Schema validation
- Adapters for agent providers
- Optional SQLite index

## Release rule

Do not describe a phase as complete until the implementation, tests, documentation, and a reproducible demo all agree.
