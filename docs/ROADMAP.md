# Roadmap

## Phase 1: runnable local MVP (complete)

- Task-card schema
- Atomic claim helper
- Folder lifecycle
- Watcher
- Digest generator
- Failure and approval lanes

## Candidate next phases

- Published JSON Schema
- Cross-platform watcher integration tests
- Adapters for agent providers
- Optional SQLite index

## Release rule

Do not describe a phase as complete until the implementation, tests, documentation, and a reproducible demo all agree.
